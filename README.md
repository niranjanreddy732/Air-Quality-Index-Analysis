# 🌍 Air Quality Index (AQI) Analysis and Machine Learning

## 📌 Project Overview
This project analyzes air quality across Indian cities using Python, exploratory data analysis (EDA), data visualization, and machine learning classification models.

## 🎯 Objectives
- Analyze AQI distribution and air quality categories.
- Identify the top 10 cities with the highest average AQI.
- Study yearly trends in average AQI.
- Explore correlations between AQI and major air pollutants.
- Compare machine learning classification algorithms.

## 🛠️ Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Spyder IDE

## 📊 Project Visualizations
The project includes:
1. Distribution of AQI Values
2. Distribution of AQI Categories
3. Top 10 Cities with Highest Average AQI
4. Correlation Matrix of AQI and Pollutants
5. Classifier Model Accuracy Comparison
6. Yearly Average AQI Trend

## 🤖 Machine Learning Models
- K-Nearest Neighbors (KNN)
- Decision Tree Classifier
- Random Forest Classifier
- Naive Bayes Classifier

## 🏆 Results
The Random Forest Classifier achieved the highest reported accuracy of **81.23%** among the four models evaluated.

## 🚀 How to Run the Project
1. Install Python.
2. Install the required libraries:
   `pip install pandas numpy matplotlib seaborn scikit-learn`
3. Keep the dataset CSV file in the same folder as the Python script.
4. Run `pythonproject2.py` in Spyder or another Python IDE.
